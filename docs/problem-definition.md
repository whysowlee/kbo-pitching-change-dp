# 상세 문제 정식화 (Problem Formulation)

본 문서는 README의 문제 정의를 수학적으로 구체화한 초안이다. 파라미터와 차원은 데이터 수집 후 확정한다.

---

## 1. 문제 개요

투수 측 감독은 경기 내내 "현재 투수를 유지할지, 불펜의 누구로 교체할지"를 반복 결정한다. 한 번 강판된 투수는 복귀할 수 없고 불펜 자원은 유한하다. 목표는 **남은 경기의 승리확률을 최대화**하는 것이며, 감독의 **위험선호**를 효용함수로 반영한다.

이는 **불확실성 하의 유한 구간 순차적 의사결정 문제**로, finite-horizon MDP / Dynamic Programming으로 정식화한다.

---

## 2. 정식화 (MDP Formulation)

### 2.1 단계 (Stage)

- 의사결정 시점 `t`: 각 타자를 상대하기 직전.
- 유한 구간: 9이닝 종료 시 종단(terminal). (연장은 확장 과제)

### 2.2 상태 (State) $s_t$

$$ s_t = (\text{inning-outs},\ \text{scorediff-bases},\ \text{fatigue},\ \text{bullpen}) $$

- **inning-outs**: 회 + 아웃카운트 (예: 7회말 1아웃)
- **scorediff-bases**: 점수차(구간화) + 루상 주자 상태(8가지 base state)
- **fatigue**: 현재 투수의 누적 피로 단계 (예: 0~3 또는 투구 수 구간)
- **bullpen**: 아직 등판 가능한 불펜 투수 집합과 각자의 능력/컨디션

> **이산화 방침**: 상태공간 폭발을 막기 위해 각 차원을 구간화한다.
> 예) 점수차 ∈ {−3 이하, −2, −1, 0, +1, +2, +3 이상}, 피로도 ∈ {낮음, 보통, 높음}.

### 2.3 행동 (Action) $a_t$

$$ a_t \in \{\text{Stay}\} \cup \{\text{Change}(p) : p \in \text{bullpen}_t\} $$

- **Stay**: 현재 투수가 다음 타자를 상대.
- **Change(p)**: 불펜 투수 `p`로 교체. 교체 후 현재 투수는 집합에서 제거(복귀 불가), `p`의 피로도는 초기값.

### 2.4 전이확률 (Transition) $P(s_{t+1} \mid s_t, a_t)$

1. 선택된 투수의 **능력 + 현재 피로도**에 따라 타석 결과 분포 $\{P(\text{out}), P(\text{walk}), P(\text{single}), \dots\}$ 결정.
2. 타석 결과 → 점수/주자/아웃 갱신 (야구 규칙).
3. 투수 피로도: 타자를 상대할수록 단계 상승 확률 증가. 교체 시 새 투수의 초기 피로도로 리셋.

> **핵심 모델링 포인트**: "피로 → 결과분포 악화" 관계가 이 프로젝트의 불확실성(Decision Analysis)의 핵심이며, 교체 결정의 trade-off를 만든다.

### 2.5 보상 (Reward)

- 중간 단계 보상은 0으로 두고, **종단 보상**만 정의 (승리확률 최대화 관점).
- 종단: 승리=1, 패배=0. → 가치함수가 곧 승리확률.
- (대안) 실점 기반 비용 모델로 확장 가능.

### 2.6 효용함수 / 위험선호 (Decision Analysis)

- 감독의 위험선호를 효용함수 $U(\cdot)$ 로 반영.
- 위험회피(보수): 리드 상황에서 분산을 줄이는 안정 지향 → 일찍 교체 경향.
- 위험중립: 기대 승리확률 그대로 최대화.
- 위험선호 파라미터를 스윕하며 정책 변화 관찰 → **민감도 분석**.

---

## 3. 최적화 (Solution Method)

유한 구간 DP **후방 귀납(backward induction)**:

$$ V_t(s) = \max_{a} \ \mathbb{E}\big[\, U(V_{t+1}(s')) \,\big|\, s, a \,\big] $$

- 종단 상태에서 $V_T(s)$ = 승/패 효용으로 초기화.
- 뒤에서부터 각 상태의 최적 행동 $a^*(s)$ 와 가치 $V_t(s)$ 계산.
- 결과물: **상태별 최적 정책표** + 상태별 승리확률.

---

## 4. 분석 계획 (Analysis)

1. **최적 정책의 형태**: 어떤 상태에서 교체가 최적인가? (피로·점수차·이닝의 임계선)
2. **경험칙 비교**: "투구 수 100개", "타순 3번째" 등 고정 규칙 정책의 승리확률 vs 최적 정책.
3. **위험선호 민감도**: 효용함수 파라미터에 따른 정책 변화.
4. **불펜 구성 민감도**: 불펜 능력치 분포가 정책에 미치는 영향.

---

## 5. 가정 & 단순화 (Assumptions)

- 상대 타선은 평균적 분포로 단순화 (초기). 타자별 매치업은 확장 과제.
- 수비/주루의 세부 불확실성은 타석 결과 분포에 흡수.
- 9이닝 종료, 연장 없음 (초기). 동점 처리 방침은 추후 정의.
- 투수 부상/돌발 변수는 모델 외.
